Welcome to Digestion Junction! A game to learn about the digestive system. Right now we've made the first segment where you need to identify and label different solutions your body uses for digestion.

How to Play:
- Click on the different flasks to add them to the beaker. Then add starch, protein or fat molecules and see how they react!
- Follow the guide on what each solution does.
- Click on the white boxes and type in what you think the flask contains (lowercase only)
- Press the check button to check if your answer is correct!

This is just one segment of Digestion Junction. Future updates will have you controlling the digestive system by using the solutions you've identified. You'll guide food down, break it up and absorb it into the body. Thanks for playing and stay tuned for more updates!
